AI API Code Examples

Practical patterns for making cost-efficient AI API calls in Python and JavaScript — authentication, token counting, streaming, caching, and batch processing.

1. Basic API Call

from openai import OpenAI

client = OpenAI(api_key="sk-...")   # Set OPENAI_API_KEY env var instead

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is a token in AI?"}
    ],
    max_tokens=200   # Always set this to control output cost
)

print(response.choices[0].message.content)
print(f"Tokens used: {response.usage.prompt_tokens} in, {response.usage.completion_tokens} out")
import OpenAI from "openai";

const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

const response = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [
    { role: "system", content: "You are a helpful assistant." },
    { role: "user", content: "What is a token in AI?" }
  ],
  max_tokens: 200   // Always set this to control output cost
});

console.log(response.choices[0].message.content);
console.log(`Tokens: ${response.usage.prompt_tokens} in, ${response.usage.completion_tokens} out`);

2. Cost Calculation Pattern

Always log token usage and calculate cost in real time so you can monitor spend:

PRICING = {
    "gpt-4o":      {"in": 2.50, "out": 10.00},
    "gpt-4o-mini": {"in": 0.15, "out": 0.60},
    "claude-3-5-sonnet-20241022": {"in": 3.00, "out": 15.00},
    "claude-3-haiku-20240307":    {"in": 0.25, "out": 1.25},
}

def calculate_cost(model, input_tokens, output_tokens):
    rates = PRICING.get(model, {"in": 0, "out": 0})
    cost_in  = (input_tokens  / 1_000_000) * rates["in"]
    cost_out = (output_tokens / 1_000_000) * rates["out"]
    return cost_in + cost_out

# After API call:
usage = response.usage
cost = calculate_cost("gpt-4o-mini", usage.prompt_tokens, usage.completion_tokens)
print(f"This call cost: ${cost:.6f}")
const PRICING = {
  "gpt-4o":      { in: 2.50, out: 10.00 },
  "gpt-4o-mini": { in: 0.15, out: 0.60 },
  "claude-3-5-sonnet-20241022": { in: 3.00, out: 15.00 },
};

function calculateCost(model, inputTokens, outputTokens) {
  const rates = PRICING[model] ?? { in: 0, out: 0 };
  return (inputTokens / 1e6) * rates.in + (outputTokens / 1e6) * rates.out;
}

const { usage } = response;
const cost = calculateCost("gpt-4o-mini", usage.prompt_tokens, usage.completion_tokens);
console.log(`This call cost: $${cost.toFixed(6)}`);

3. Streaming (Reduce Perceived Latency)

Streaming doesn't reduce cost — it improves user experience by showing tokens as they arrive instead of waiting for the full response.
with client.chat.completions.stream(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Explain prefix caching briefly."}],
    max_tokens=300
) as stream:
    for chunk in stream:
        if chunk.choices[0].delta.content:
            print(chunk.choices[0].delta.content, end="", flush=True)

# Get final usage after streaming
final = stream.get_final_completion()
print(f"\nTotal tokens: {final.usage.total_tokens}")
const stream = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "Explain prefix caching briefly." }],
  max_tokens: 300,
  stream: true
});

for await (const chunk of stream) {
  const delta = chunk.choices[0]?.delta?.content ?? "";
  process.stdout.write(delta);
}

4. Anthropic Prompt Caching

Cache long system prompts to save up to 90% on repeated calls with the same prefix:

import anthropic

client = anthropic.Anthropic()

response = client.messages.create(
    model="claude-3-5-sonnet-20241022",
    max_tokens=1024,
    system=[{
        "type": "text",
        "text": "You are a legal document analyst. " + very_long_context,  # 2000+ tokens
        "cache_control": {"type": "ephemeral"}  # Cache this prefix!
    }],
    messages=[{"role": "user", "content": "Summarize the liability section."}]
)

# Check cache hit in response headers
print(f"Cache read tokens: {response.usage.cache_read_input_tokens}")
print(f"Cache creation tokens: {response.usage.cache_creation_input_tokens}")
# Cache reads cost 10% of normal input price = 90% savings on cached content

5. Error Handling & Retry Logic

import time
from openai import RateLimitError, APIError

def call_with_retry(client, **kwargs, max_retries=4):
    """Exponential backoff for rate limits and transient errors."""
    for attempt in range(max_retries):
        try:
            return client.chat.completions.create(**kwargs)
        except RateLimitError:
            wait = 2 ** attempt   # 1s, 2s, 4s, 8s
            print(f"Rate limited. Waiting {wait}s...")
            time.sleep(wait)
        except APIError as e:
            if e.status_code >= 500:   # Server error — retry
                time.sleep(2 ** attempt)
            else:
                raise                  # Client error — don't retry
    raise Exception("Max retries exceeded")
