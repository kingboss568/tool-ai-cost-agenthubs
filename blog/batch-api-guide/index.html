Batch API Guide: Cut AI Costs by 50% for Non-Real-Time Workloads

Both OpenAI and Anthropic offer batch APIs that process requests asynchronously at 50% of the standard price. If any significant portion of your workload isn't time-sensitive, this is the most impactful single change you can make.

💡 50% Discount — No Catches

OpenAI Batch API and Anthropic Message Batches both offer exactly 50% off standard pricing. The only tradeoff: results return within 24 hours instead of milliseconds.

When to Use Batch APIs

Batch APIs are perfect when:

  • Results are needed within hours, not seconds
  • You process large volumes of documents, records, or items
  • The workload is scheduled (nightly, weekly processing)
  • Users won't be waiting for an immediate response

Common use cases: document classification, content moderation, data enrichment, report generation, batch translations, SEO content generation, product description writing, and email/newsletter personalization.

OpenAI Batch API: Step-by-Step

Step 1: Prepare Your Batch File

Create a JSONL file where each line is one request:

{"custom_id": "request-1", "method": "POST", "url": "/v1/chat/completions", "body": {"model": "gpt-4o-mini", "messages": [{"role": "user", "content": "Classify this review as positive, negative, or neutral: 'Great product, fast delivery!'"}], "max_tokens": 10}}
{"custom_id": "request-2", "method": "POST", "url": "/v1/chat/completions", "body": {"model": "gpt-4o-mini", "messages": [{"role": "user", "content": "Classify this review: 'Terrible experience, never again.'"}], "max_tokens": 10}}

Step 2: Upload the File

from openai import OpenAI

client = OpenAI()

# Upload the batch file
with open("batch_requests.jsonl", "rb") as f:
    batch_file = client.files.create(file=f, purpose="batch")

print(f"File uploaded: {batch_file.id}")

Step 3: Create the Batch

batch = client.batches.create(
    input_file_id=batch_file.id,
    endpoint="/v1/chat/completions",
    completion_window="24h"
)
print(f"Batch created: {batch.id}")
print(f"Status: {batch.status}")

Step 4: Check Status and Retrieve Results

import time

# Poll for completion (or use webhooks in production)
while True:
    batch = client.batches.retrieve(batch.id)
    if batch.status == "completed":
        break
    time.sleep(60)  # Check every minute

Anthropic Message Batches: Step-by-Step

import anthropic

client = anthropic.Anthropic()

# Create a batch
message_batch = client.messages.batches.create(
    requests=[
        {
            "custom_id": "doc-001",
            "params": {
                "model": "claude-3-haiku-20240307",
                "max_tokens": 100,
                "messages": [
                    {"role": "user", "content": "Summarize in one sentence: [document text here]"}
                ]
            }
        },
        # Add up to 10,000 requests per batch
    ]
)

print(f"Batch ID: {message_batch.id}")

# Check and retrieve results
batch = client.messages.batches.retrieve(message_batch.id)
if batch.processing_status == "ended":
    for result in client.messages.batches.results(message_batch.id):
        print(f"{result.custom_id}: {result.result.message.content[0].text}")

Batch API Limits to Know

  • OpenAI: Up to 50,000 requests per batch, results within 24 hours
  • Anthropic: Up to 10,000 requests per batch, results within 24 hours
  • Batch jobs can fail if the batch file has formatting errors — validate before submitting
  • Compute window guarantees completion within 24 hours, but usually much faster (1–4 hours)
