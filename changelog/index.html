v2.0.0 June 1, 2025 Major Release
🚀 Launch
🚀
Major expansion to 50 pages — complete suite of AI cost tools, reference pages, workspace, blog, and community pages.
✨ New Features
✨
Model Comparison Tool — side-by-side comparison of any two AI models across cost, speed, and context window. Compare pricing, token limits, and performance benchmarks in a single view.
✨
Token Counter — real-time token counting for text and code input. Counts tokens using tiktoken-equivalent logic, with per-model cost projection.
✨
ROI Calculator — calculate return on investment for AI features with customizable value assumptions.
✨
Budget Planner — monthly AI budget planning across multiple use cases and models with scenario modeling.
✨
Batch Calculator — calculate savings from using Batch API endpoints (50% cost reduction for async workloads).
✨
Model Picker Wizard — guided model selection wizard with use-case-based recommendations.
✨
Project Estimator — end-to-end cost estimation for AI projects with multi-stage pipeline support.
✨
Prompt Optimizer — analyze prompts for token efficiency and get suggestions for reducing overhead.
✨
Usage Analyzer — analyze API usage patterns and identify cost optimization opportunities.
✨
Cost Breakdown Tool — detailed cost breakdown across input tokens, output tokens, images, and audio.
✨
Advanced Calculator — multi-variable calculator for complex pipeline cost estimation.
✨
Token Converter — convert between tokens and words/characters for different model families.
✨
Complete UI Redesign — glassmorphism topbar, gradient hero sections, responsive sidebar navigation, and world-class design system.
✨
AI Models Database — comprehensive database of 17+ AI models with pricing, context windows, and benchmark scores.
✨
Benchmarks Comparison — MMLU, HumanEval, MATH, and GSM8K scores for all major models in a sortable table.
✨
Glossary — 40+ AI pricing and technology terms defined clearly for developers and business users.
✨
Blog Section — in-depth articles on AI cost optimization, model selection, prompt engineering, and enterprise AI management.
✨
AdSense Integration — Google AdSense with auto ads across all pages, supporting the free tier of the product.
