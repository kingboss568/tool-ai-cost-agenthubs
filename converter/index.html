Conversion reference

Tokens to words

1 token ≈ 0.75 English words. A typical 500-word essay is about 667 tokens. Technical content with numbers and code runs higher (~0.5 words per token).

Tokens to characters

1 token ≈ 4 characters in English. Non-English languages and code may tokenize differently — Asian languages often use 1-3 characters per token.

Pages to tokens

A standard page (250 words, ~12pt font) ≈ 333 tokens. A 10-page report ≈ 3,330 tokens. A 300-page novel ≈ 100,000 tokens.
