How to reduce each cost component

Input token cost

Use prompt caching for repeated system prompts (90% discount on cached tokens). Compress prompts with the Prompt Optimizer. Consider shorter context windows where possible.

Output token cost

Output tokens are typically 4-6x more expensive than input. Request shorter responses with explicit length constraints. Use structured JSON output to avoid verbose prose.

Image & audio costs

Resize images before sending to vision APIs — smaller images use fewer tokens. For audio, use lower sample rates and compress before transcription. Batch audio jobs where possible.
