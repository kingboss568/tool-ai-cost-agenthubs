Getting Started

How do I use the cost calculator?

Open the Cost Calculator and set your model tier (Economy, Balanced, or Premium), then enter your daily request volume, input tokens per request, and output tokens per request. The result panel updates in real time showing your estimated monthly cost with low, expected, and high ranges.

Click "Save project" to store your configuration in your browser for later reference, or "Copy output" to paste the estimate into another tool.

What is a token?

A token is the basic unit of text that AI models process. Roughly speaking, 1 token ≈ 4 characters ≈ 0.75 words in English. "Hello world" is about 2 tokens. A typical short email is about 200–400 tokens.

Every API call has input tokens (what you send, including the system prompt and conversation history) and output tokens (what the model generates). Providers charge separately for each, usually at different rates — output typically costs more.

Use our Token Counter to estimate token count from any text.

How accurate are the pricing estimates?

Estimates are based on current published pricing from each provider's documentation, updated regularly. However, actual costs may vary due to:

  • Pricing changes by providers (can happen without notice)
  • Volume discounts you may have negotiated
  • Overhead from API infrastructure, retries, and rate limiting
  • Caching (can significantly reduce costs)

Always verify current pricing with your provider before committing to a budget. Our estimates are planning tools, not billing guarantees.

How do I save my work?

Click the "Save project" button in any tool. Your configuration is saved to your browser's localStorage — no account or server is needed. You can view saved projects in the Workspace page.

To export your data permanently, use "Download JSON" which saves a file to your device. This is useful for backup or sharing with teammates.

Note: localStorage is device-specific. Clearing your browser data will delete saved projects.

Calculators

How does the Model Comparison tool work?

The Model Comparison tool lets you select up to 3 AI models and enter your usage parameters (daily requests, input tokens, output tokens). It calculates the monthly cost for all three simultaneously and highlights the cheapest option with a "Winner" badge.

All pricing data is embedded in the page and calculated client-side — no API calls to pricing services.

How do I calculate ROI for AI implementation?

Use the ROI Calculator. Enter your current labor costs (hours × hourly rate), the percentage of tasks AI can automate, the monthly AI cost, and any setup costs. The calculator outputs monthly savings, annual savings, payback period in months, and 3-year ROI percentage.

How does the Batch Calculator work?

The Batch Calculator compares the cost of processing requests in real-time vs using batch APIs (which offer 50% discounts from OpenAI and Anthropic). Enter your model, number of documents, and token counts to see both costs and the savings from switching to batch processing.

How does the Model Picker wizard work?

The Model Picker asks you 6 questions: use case, quality requirement, speed need, context window size, budget, and privacy requirements. Based on your answers, it scores all models in our database and recommends the top 3 with explanations of why each fits your criteria.

Pricing Data

How often is pricing data updated?

We aim to update pricing data within a week of major provider changes. AI pricing is volatile — OpenAI, Anthropic, and Google all make unannounced changes periodically. We can't guarantee real-time accuracy.

For the most current pricing, always check:
• OpenAI: platform.openai.com/pricing
• Anthropic: anthropic.com/pricing
• Google: cloud.google.com/vertex-ai/pricing

Why do providers charge differently for input vs output?

Generating output (completion) requires significantly more compute than processing input (prefill). During generation, the model must run one "forward pass" per token generated, while input processing can be done in parallel. This is why output tokens typically cost 3–6× more than input tokens across all major providers.

How do batch API discounts work?

Both OpenAI and Anthropic offer batch APIs that process requests asynchronously (results returned within 24 hours) at exactly 50% of the standard real-time price. This makes batch APIs ideal for any workload where immediate response isn't required — document processing, classification, content generation, etc.

See our Batch Calculator or read the Batch API Guide.

Workspace & Data

Can I export my data?

Yes. In any tool, click "Download JSON" to export the current project as a JSON file. You can also click "Copy output" to copy formatted text to your clipboard.

From the Workspace, you can view and download all saved projects.

Is my data shared with anyone?

No. All calculations happen in your browser using JavaScript. Nothing you type into the calculators is sent to our servers (we don't have application servers — the site is static HTML on GitHub Pages).

The only external services involved are Google AdSense (which may set cookies for ad targeting) and GitHub Pages (for serving the static files). See our Privacy Policy for details.

Does this tool work offline?

Mostly yes, once the page has loaded. All calculations are JavaScript-based. However, AdSense ads won't load offline, and some features that depend on external resources may be limited. The core calculators work fully offline after initial page load.
