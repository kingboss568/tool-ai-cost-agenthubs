Understanding This Data

Token Pricing

All prices shown per million tokens. To calculate cost per request: (input_tokens × input_rate + output_tokens × output_rate) / 1,000,000. A typical chat message is 200–800 tokens in, 100–500 tokens out.

Context Window

The maximum number of tokens a model can process in one call (input + output combined). Larger windows allow longer documents and conversations but may cost more on long-context providers.

Speed Ratings

  • Very Fast — >150 tok/s, <10ms/tok latency
  • Fast — 70–150 tok/s, 10–25ms/tok
  • Moderate — 40–70 tok/s, 25–40ms/tok
  • Slow — <40 tok/s (often reasoning models)
