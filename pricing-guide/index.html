1. How AI API Pricing Works

AI API providers charge based on the number of tokens processed in each API call. Every time you send a request to an AI model, you're charged for two things: the tokens you send (input) and the tokens the model generates back (output). These two rates are almost always different, with output typically costing more.

The pricing unit is typically expressed as cost per million tokens ($/M tokens), though you're only charged for what you actually use. A request using 1,000 tokens at a $1/M rate would cost exactly $0.001.

The Basic Formula Cost per request = (input_tokens × input_rate + output_tokens × output_rate) ÷ 1,000,000

For example, a GPT-4o request with 500 input tokens and 200 output tokens costs: (500 × $2.50 + 200 × $10.00) / 1,000,000 = $0.001250 + $0.002000 = $0.003250 per request.

At 10,000 requests/day that's $32.50/day or ~$975/month. This is why understanding token costs is so critical before scaling.

2. What Is a Token?

A token is the basic unit of text that AI models process. Tokens are not the same as words — they're fragments of words determined by a tokenization algorithm. Most modern LLMs use a variant of Byte-Pair Encoding (BPE) to split text into tokens.

Token Length Rules of Thumb

  • 1 token ≈ 4 characters of English text
  • 1 token ≈ 0.75 words (or ~100 tokens ≈ 75 words)
  • Common words are often 1 token: "the", "cat", "run"
  • Long or uncommon words may be 2–4 tokens: "tokenization" = 3 tokens
  • Numbers and code are often more expensive: "12345" may be 5 tokens
  • Non-English text often costs more tokens per word
Practical Estimates A tweet (280 chars) ≈ 70 tokens · A page of text (500 words) ≈ 667 tokens · A short story (10,000 words) ≈ 13,333 tokens · An average codebase file (200 lines) ≈ 1,500–2,500 tokens

3. Input vs Output Pricing

Almost every AI provider charges more for output tokens than input tokens. The ratio varies, but output typically costs 3–5x more than input. This is because generating each output token requires a full forward pass through the model, while reading input tokens can be batched more efficiently.

Implications for Your Design

  • If your use case generates long outputs (essays, code, reports), output costs will dominate your bill
  • For classification or short-answer tasks, input costs dominate
  • Adding system prompt context (input) is usually cheaper than expecting the model to reason more (output)
  • Streaming responses doesn't change cost — you pay for all output tokens regardless

4. Context Window Pricing

The context window is the maximum number of tokens a model can process in one call (input + output combined). Larger context windows are more expensive to serve, and some providers add surcharges for very long contexts.

How Context Affects Cost

When you maintain a conversation history or include a large document in every request, the full history is re-sent as input each time. A 10-message conversation that started with a 2,000-token system prompt might use 8,000 input tokens even for a simple question.

Watch out for conversation cost growth! A 20-turn conversation with 1K tokens per turn can accumulate 20K input tokens by the final message. With GPT-4o at $2.50/M, that one final message costs $0.05 in input alone — 10× more than the first message.

Long Context Pricing Tiers

Google's Gemini 1.5 Pro and Flash charge different rates for requests over 128K tokens, making them cost-effective for long contexts compared to alternatives. For contexts under 128K, most models charge their standard rate.

6. 10 Cost Optimization Strategies

01
Use the Right Model Tier
Don't use GPT-4o for simple classification. Route tasks to the cheapest model that meets your quality threshold. Build an evaluation set to test model tiers against each other.
40–80% savings
02
Implement Prompt Caching
Anthropic and OpenAI offer prompt caching that can reduce costs by up to 90% when your system prompt is repeated across many requests. Cache your large system prompts and reference documents.
50–90% savings
03
Use Batch API
For non-real-time workloads, OpenAI's Batch API offers 50% discounts with 24-hour SLA. Perfect for content generation, data extraction, and analysis pipelines that don't need instant responses.
50% savings
04
Trim Your System Prompt
Every word in your system prompt is paid for with every request. Audit your prompts — remove redundant instructions, use concise language. A 500-token reduction saves $0.00125 per GPT-4o request.
10–30% savings
05
Limit Output Length
Set max_tokens to cap output at what you actually need. If you only need a yes/no decision, tell the model that explicitly. Output costs 3–5× more than input, so every saved output token counts double.
20–50% savings
06
Cache API Responses
For deterministic or near-deterministic prompts, cache the output at the application layer (Redis, database). A cached response has zero token cost. Even 20% cache hit rate meaningfully reduces bills.
20–60% savings
07
Compress Context History
Instead of passing full conversation history, summarize older messages. A 20-message history can be summarized into 300 tokens without losing context continuity, versus sending 10,000 tokens.
30–70% savings
08
Use Structured Output
Request JSON output with a strict schema instead of verbose prose. "{"sentiment": "positive", "score": 0.92}" uses far fewer tokens than a paragraph explanation. Use response_format: json_object.
30–60% savings
09
Fine-tune Small Models
For high-volume repetitive tasks, fine-tuning a smaller model on your domain data can match a larger model's performance at a fraction of the inference cost. Amortize fine-tuning cost over millions of requests.
60–90% savings at scale
10
Set Spending Limits
Enable hard limits in your API provider dashboard. Use our Budget Planner to calculate safe monthly allocations. Implement per-user rate limiting in your application to prevent runaway costs.
Prevents cost overruns

10. Hidden Costs to Watch For

  • Retry costs: Failed API calls that are retried still consume tokens if the request was received. Always implement exponential backoff to avoid duplicate charges.
  • Function/tool call tokens: Function definitions added to your request (for tool use) count as input tokens. A large tool schema can add 200–1000 tokens per request.
  • System prompt overhead: Your system prompt is counted as input tokens on every request, even if it never changes.
  • Streaming overhead: Some providers have minimum billing increments even for very short outputs.
  • Taxes and fees: EU providers may add VAT; some platforms add platform fees on top of model costs.
  • Overage costs: Exceeding rate limits doesn't always result in errors — some providers continue serving at higher per-token costs.
  • Image tokens: Vision requests encode images as tokens. A 1024×1024 image in GPT-4o costs ~765 input tokens ($0.0019) regardless of how few words describe it.
