Tips to reduce token count

  • Remove unnecessary filler words and pleasantries — "Please kindly" can become "Please"
  • Use bullet points instead of paragraphs for structured data — reduces 20-30% tokens
  • Avoid repeating context the model already has — reference it briefly instead
  • Use abbreviations for common terms after first definition (e.g., "large language model (LLM)")
  • Remove examples if the task is clear enough without them
  • Consider prompt caching for system prompts used repeatedly (saves 90%+ on cached tokens)
